2. IMAGE PACKAGE AND STORAGE
User confirmed Intervention Image is instructor approved and authorized installation. Installed intervention/image 3.11.10 and its intervention/gif 4.2.4 dependency, recorded in composer.json/composer.lock. GD is the processing driver; GD is installed locally and must be installed on another host.

Edit User accepts JPG/JPEG, PNG, WebP and GIF up to 2048 KB, with a 4096-pixel per-axis dimension limit. Intervention Image prepares 256 x 256 PNG thumbnails. Storage::disk('public')->put() writes processed bytes to avatars/<UUID>.png. Only the relative path is stored. No move() or database binary data is used. Empty uploads preserve the existing avatar; missing files use the same local placeholder as null paths. Processing/write failures return validation errors; a database save exception cleans up the new file. Replaced historical avatar files are retained to avoid deleting existing uploads.
